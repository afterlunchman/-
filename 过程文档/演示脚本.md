# 2 分钟演示脚本

> 录屏要求：画面中可见本人学号与姓名；真实运行，至少展示一个难例；总时长 ≤ 2 分钟。

## 录制前准备

1. 启动界面：`.venv/Scripts/python.exe -m streamlit run src/app/streamlit_app.py`
2. 浏览器打开 `http://localhost:8501`，缩放调到 100%。
3. 侧边栏检索器选 `hybrid`，关闭“启用重排”（CPU 上重排较慢）。
4. 在浏览器书签栏或页面角落放一张写有「学号 姓名」的便签，确保全程可见。
5. 提前把四个示例问题跑一遍，确认 API 可用。

## 分镜

| 时间 | 操作 | 讲解要点 |
| --- | --- | --- |
| 0:00—0:15 | 展示首页与侧边栏 | 155 份制度、4,976 个条文块；支持 BM25 / 词向量 / BGE / hybrid |
| 0:15—0:40 | 输入「宿舍可以使用大功率电器吗？」并提问 | 指出答案中的结论、4 条引用、条号与官网/PDF 链接 |
| 0:40—1:00 | 展开「检索 Top-k 与分数」 | 说明命中条款、置信度、OCR 低置信提示 |
| 1:00—1:25 | 输入「补考成绩怎么算？」并提问 | 难例：系统拒答并建议咨询部门，不编造答案 |
| 1:25—1:45 | 侧边栏切换 `bm25` 与 `dense`，重复第一个问题 | 对比关键词与向量检索的 Top-k 差异，呼应检索评测 |
| 1:45—2:00 | 回到 hybrid，展示延迟与 token | 报告 P95 延迟、引用校验通过率与总成本 |

## 难例备选

- 「可以让外校同学留宿吗？」：边界/否定类，观察检索是否命中宿舍管理制度第四条。
- 「实验室发生事故后多久内要报告？」：数值/期限类，观察是否给出准确时限并引用条号。
- 「补考成绩怎么算？」：语料外主题，必须拒答。
